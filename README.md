# Osemoji

Emoji file icons and interface icons for VS Code. Osemoji draws them with your computer's own emoji, so they match the rest of your system.

## Turn it on

- **File icons:** run `Preferences: File Icon Theme` and pick **Osemoji File Icons**.
- **Interface icons:** run `Preferences: Product Icon Theme` and pick **Osemoji Product Icons**.

## Good to know

- The emoji come from your operating system, so they can look different between systems and system versions.
- Interface icons appear slightly larger than VS Code's own, because VS Code doesn't let icon themes set their size.
